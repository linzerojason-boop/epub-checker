EPUB 完整性检查工具  使用说明（v3.15）
=====================================

【v3.11 修了哪些问题】
按外部代码审查报告逐条核对后修掉这些：
1) 两次比对「部分重叠」时摘要格式串写错，以前会直接显示「失败」，现在正常给结论。
2) 合集检查页以前 100% 显示「检查失败：too many values to unpack」，已修好。
3) 结论过滤下拉以前选「不一致」永远 0 行、选「一致」混进别的档，现在按真实状态精确过滤。
4) 目录检查对「第一章」「第01话」这类纯编号标题以前配不上，现在能配。
5) 生成目录时文件写在子目录的情况下，href 以前会多叠一层目录名，现在按实际位置换算。
6) 给已有封面的书换封面时，manifest 里会出现两个 cover-image，现在 id 自动去重；旧封面页已在 spine 首位时也不再插第二个。
7) 目录里 href="#" 自引用、同一文件不同锚点，以前会被误报成「没有 href / 重复出现」，现在不再误报。
8) 编辑工具换一本书时清单不刷新，现在会跟着换。
9) 「第 4 步 修复重复目录项」以前只认 .ncx 后缀，像 xml/vol.nav 这种也会修了。
10) 任务表去掉了那个空列；取消以后状态文字不会再被「完成」盖掉；比对进行中「合并 EPUB…」入口也会锁住。
11) 还有一条没做：同一文件靠锚点分节的目录（如 #filepos123）仍无法重建，需要单独做，见交接文档第 15 节。

【编辑工具：目录改成分三步】
  第 1 步 整理章节清单、第 2 步 检查目录结构（只看，不动原书）、
  第 3 步 写进新文件（原书不动，另存一本，nav 和 ncx 一起写）。
  三步各有一个框，不会再和「检查」混在一起。

【封面：大预览，可直接拖图】
  封面页左边是 240×240 的预览框：可以点它从文件里选图，
  也可以把图片直接拖到窗口里（已经选好书的前提下）。
  选好后点「添加封面并另存…」；想换一张先点「清除」。

【加文件更顺手】
  比对页不用非得点「添加文件」：点列表空白处也会弹选择框；
  任何一次选文件后，下次对话框都会从上次的目录开始。

【结论过滤与导出 CSV 挪了位置】
  「只看 全部 ▾」和「导出 CSV」现在在比对页里、任务表上方，
  侧栏只留四个功能入口 + 进度 + 状态。


【目录页第 4 步：修复重复目录项】
合并后的书（尤其 EpubMerge 产的）常出现「父项与其唯一子项标题、链接都一样」的重复目录项。
把书拖进编辑工具，点「修复目录重复并另存…」即可：顺手把 ncx 的 playOrder 重排、dtb:depth 归 1。
没有重复就不写文件，报告会写「没有发现重复目录项」；有改动另存为 <原名>_修复.epub，原书不动。
【v3.15 拖拽修好了】
1. 以前只有拖到窗口边缘的空白处才算数，拖到文件列表上（也就是最自然的位置）没反应。
   现在拖到列表上、拖到空白处、拖到「合并 EPUB」的书名列表上都行。
2. 「合并 EPUB」页的书名输入框不再把拖进来的文件当文字吞掉。
3. 「添加文件」按钮旁边的空列表区域，点一下也能加文件。
【v3.14 修了功能测试报告里的 4 个问题】
1. 合并 EPUB 一点「开始合并」就报 TypeError（进度回调参数个数对不上）——现在
   不管回调要几个参数都能工作，合并按钮恢复可用。
2. 替换已有封面时，EPUB 里会出现两条「封面图」标记（cover-image / cover-image2）——
   现在会把旧标记摘掉再写新的，只会有一条。
3. 合集检查里若有分册是「无法比对」的，以前仍会下结论「所有分册内容均已在合集中
   找到」，会误导——现在结论里会说明「有 N 本分册无法比对（未计入缺失统计）」。
4. 合集报告末尾原叫「合集未被任何分册匹配的页(疑似重复页)」，其实大多数只是「最像
   的那页」，MAD 差很远——现在改叫「合集里未被任何分册匹配的页: N（其中与另一页
   几乎相同: M）」，只有 MAD < 2.0 才算「几乎相同」。
（另：功能测试报告里提到的「目录锚点 #filepos 重建」仍未做，属独立需求。）

【v3.13 内部结构整理（使用者看不出差别）】
1. 比对页的构建代码拆成「文件区 + 结果区」两段，以后加功能不用动一大坨。
2. 所有后台任务统一走同一条线程通道（原来 7 处各写一遍）。
3. 界面、行为、快捷键、结论判定都和 v3.12 一样，测试 157 项依旧全绿。

【v3.12 重构与提速】
· 程序内部拆成 4 个模块（解析 / 检查比对 / 编辑合并 / 门面），对外行为完全不变，157 项自动化测试全绿。
· 页面图指纹改成多线程解码：一本 2147 页的扫描书，出指纹从约 25 秒降到约 3.9 秒。
· 新增磁盘缓存：算过的页面指纹存到 %LOCALAPPDATA%\epub_checker\cache（上限 512MB，自动清理旧的）。同一本书第二次比对几乎不用等（实测 0.0 秒）。
· 合并 EPUB、加目录、加封面时改成边读边写：500MB 级别的书不再一次性吃掉几百 MB 内存。
· 修了「开始比对后立刻点取消没反应」的竞态。
· 尚未做：界面结构拆分、单文件多锚点（filepos）目录重建（后者单独立项）。
【v3.18 可以切英文界面】
  · 侧栏「Language / 语言」里选：跟着系统 / 中文 / English，立刻生效，下次启动还记得。
  · 界面文字全部会跟着变（按钮、表头、结论、页签、页头说明）。
  · 底部「详细报告」的正文也会翻成英文（报告标题、字段名、结论句、逐条差异的小标题）。
  · 书名、文件路径、章节名这类书里的数据保持原样，不翻译。

【界面已改成四个页签】
  左侧栏：比对 / 编辑工具 / 合并 EPUB / 合集检查，点一下就切换右侧整页，不再弹窗。
  四个页面都支持把文件或文件夹直接拖进来；比对页拖左框进基准（A），拖右框进待检（B）。
  空列表上会显示「把文件或文件夹拖到这里」的提示。

【编辑工具：清单会自动填】
  选好（或拖入）一本书后，程序会把这本书现有的目录填进「章节清单」作为草稿，
  你可以直接改、删、加行，再点「检查目录」或「生成目录并另存…」。
  书里没有目录时清单为空，需要自己粘贴。

【启动】
双击 epub_checker.bat 即可启动图形界面。启动器自动使用随包 Python 环境（含 PySide6），无控制台窗口。

【支持的文件类型】
EPUB（.epub）、MOBI/AZW（.mobi / .azw / .azw3 / .prc）、PDF（.pdf）。

【界面】
上部左右两栏：「基准（A）」和「待检（B）」。每栏都有 添加文件 / 添加文件夹 / 移除选中 / 清空。
中部一行：开始比对 / 取消 / 进度条 / 结论过滤 / 导出 CSV / 合集检查。
下部三个页签：「任务表」「详细报告」「合集检查」。

【拖放】
直接把文件或文件夹拖到左边或右边的列表里即可——拖到哪个列表就加进哪一栏，不再按文件个数猜。
文件夹会自动展开（只收电子书格式，忽略其他文件和 0 字节文件）。
重复文件按路径去重，底部状态栏会提示「已添加 N 个 / 忽略 M 个重复 / 拒绝 K 个（原因）」。

【比对】
1. 左栏放基准书，右栏放待检书，点「开始比对」。
   任务数 = A 的文件数 × B 的文件数（例如 3 × 4 = 12 个任务），表格按顺序列出，不会错位。
   超过 100 个任务会提示，超过 1000 个会确认耗时，超过 5000 个直接拒绝。
2. 每行结论：
   ✓ 一致 —— 资源清单与文本完全相同
   ≈ 合集内含 —— 两边是同一本书的不同打包：基准的章节（或页面）基本都在待检的合集里
                  （合集多出别的卷不算差异；反过来待检整本在基准里也一样判合集内含）
   ~ 部分一致 —— 部分章节文本相同、部分不同
   （判定按实质内容覆盖率：200 字以上的章节才算数，titlepage/版权页这类样板页不算；覆盖率 >=60% 且基准章节全部找到 → 合集内含，>=30% → 部分一致，低于 30% → 一律存在差异。）
   ✗ 存在差异 —— 资源清单或文本有实质差别
   ⛔ 无法比对 —— 跨格式且两侧都没有可比的页面图（例如 EPUB↔MOBI）、或加密文件
                  （扫描版 PDF ↔ 图片版 EPUB 会自动改按页面图比对，见下面「扫描版 / 图片版自动回退」）
   ⏭ 跳过 —— 左右是同一个文件
   失败 —— 文件损坏/不是合法 EPUB 等，具体原因写在「差异摘要」
3. 「格式关系」列显示 同格式 / 跨格式，方便一眼看出哪些行只是比不了。

【扫描版 / 图片版自动回退】
有些书是扫描件：PDF 每页就是一张图，EPUB 里也没有像样的文字。这时工具会自动改按「页面图比对」：
- 每张页面图先缩成 32x32 灰度指纹粗筛候选，再用像素平均差确认，按差值从小到大一对一配对。
- 同一页出现多次（卷首/扉页重复）算一致；两侧页数不一样会写明多几页、少几页。
- 摘要举例：「页面图片比对：基准 2147 页 / 待检 2147 页，100% 能对应上，其中 100 页是重复页，1 页对不上（多半是渲染/裁边差异）」。
- 耗时：2147 页约 25-45 秒（要解码 4000 多张图，慢是正常的），进度条期间的阶段文字会显示「按页面图片比对」。
- 只有两侧都至少有 3 张页面图才走回退，否则仍报「无法比对」并写明原因。
- 单卷 vs 合集：小册子 95% 以上页面在大合集里找到就判「≈ 合集内含」（10 页里 1 页对不上属正常），
  摘要会写「基准的 199 页基本全在待检的 2147 页里，1 页对不上」。
- 缓存：已算过的书在内存里保留（最多约 12000 页），12 卷对同一本 2147 页合集时，第一对约 14 秒，
  之后每对约 1.5 秒。

【任务表】
- 点表头可以排序；「结论」下拉可以过滤（全部 / 一致 / 合集内含 / 存在差异 / 部分一致 / 无法比对 / 失败 / 已取消 / 跳过）。
- 差异摘要是一句话说明，列宽够放下；失败行有浅红底色，结论列带颜色和图标。
- 右键菜单：复制该行 / 查看详情 / 打开所在文件夹。
- 双击某行跳到「详细报告」页，显示这本书的单文件诊断：zip 完整性（CRC）、manifest 缺文件、spine 无效引用、图片断链、孤儿图片提示、章节列表；MOBI 显示记录数与正文图片页数，PDF 显示页数与内嵌图片数。
  两栏内容不同的书还会附上「与「X」的逐条差异」：哪些章节内容相同只是路径不同、哪些路径相同但内容不同，一眼看清差在哪。

- 底部结果框的主体永远是**待检（B）文件**的诊断报告，标题写明「待检（B）：… ｜ 基准（A）：…」；
  检查跑完会自动把第一条的报告铺到框里，不用再双击。
【取消与关窗】
跑的过程中可以点「取消」：尚未开始的任务标「已取消」，正在跑的那条收尾后标「已中断」。
直接关窗口也会先取消并在 2 秒内退出，不会卡死。

【导出】
「导出 CSV」把任务表导出为 UTF-8-BOM 的 CSV，Excel 直接打开不乱码。

【合集检查】
点「合集检查」按钮弹出独立对话框：选 1 本合集文件，添加 N 本分册（可混合 EPUB/MOBI/PDF），点「开始检查」。自动识别图片版/文字版：
- 图片版（漫画）：逐页像素比对，报告每卷「匹配 / 疑似降质 / 缺失 / 重复匹配」，并列出合集内「疑似重复页」。
- 文字版：逐章文本比对，报告缺章。
- 结论行直接给出「是否缺失」。
对话框里的报告可以另存为 txt。检查期间可点「取消」，但要等当前步骤结束才停。

【编辑工具（只针对 EPUB）】
点中部「编辑工具…」按钮，用右栏「待检（B）」第一本书打开编辑对话框（两个页签）。
· 目录页：
  - 上方是「章节清单」：每行一条，可以写成「第1章 -> titlepage.xhtml」，也可以用「-」或「|」分隔；
    行首缩进（或 1.1 这种编号）表示层级；「从文件导入…」可以读 .txt/.md（自动试 UTF-8/GBK/UTF-16）。
  - 点「检查目录」：先看书自身结构（有没有 nav/ncx、目录项指向的文件是否存在、是否有重复、层级是否跳级），
    再和清单比对，报告「清单有、书里没有」「书里有、清单没有」「顺序不一致」「层级不一致」。
  - 点「生成目录并另存…」：按清单重写 nav.xhtml 和 toc.ncx（EPUB3/EPUB2 双写），另存成「原名_加目录.epub」。
    只有检查结果为「无错误」时才允许生成；目标文件重名会自动加 (2)。
· 封面页：
  - 「选择图片…」后点「应用封面」，另存成「原名_加封面.epub」。图片超过 2000px 边或 2MB 会先缩到 1600px 再转 JPEG。
  - 如果原书已经有封面，会弹框问「跳过 / 替换 / 取消」，默认不动原封面。
  - 新封面会写成 OPF 里的封面图（properties="cover-image" + meta name="cover"），并在书脊首位插一个封面页。
· 共同规则：一律另存新文件，从不修改原书；写盘时先写 .part 再自检（CRC、mimetype、目录项可解析）后原子替换，
  检查不通过会删掉半成品并提示原因。只支持 EPUB，其他格式按钮是灰的。

【侧栏四个入口（v3.7）】
  侧栏从上到下：比对 / 编辑工具… / 合并 EPUB… / 合集检查…，下面是过滤、导出、进度和阶段提示。
  · 比对：左边「基准（A）」放你手上的版本，右边「待检（B）」放要检查的版本，点「开始比对」。
  · 编辑工具…：给单本 EPUB 检查/写入目录、加封面，永远另存新文件。
  · 合并 EPUB…：多本 EPUB 合成一本（按列表顺序，可上移/下移），支持自然排序书名、
    自动取第一本封面或指定封面图，输出为独立的合并文件，不改动原书。
  · 合集检查…：用一本合集去核对多个分册的图片是否齐全。

【合并 EPUB 的产物结构】
  合并结果与 EpubMerge 同构：顶层 mimetype / META-INF/container.xml /
  EPUB/package.opf / EPUB/nav.xhtml / EPUB/toc.ncx / EPUB/cover.jpg，
  每本书原样放在 EPUB/book_001/、EPUB/book_002/… 下，目录为「每本书一节 + 书内目录」两层。
  生成后会自动自检（目录项是否都能找到文件、mimetype 是否为第一条），通过后才落盘。

【打包成 exe】
  目录里已经带了打包脚本：双击「打包exe.bat」会调用 PyInstaller 生成
  dist\EPUB检查器.exe（约 56 MB，单文件，可直接拷给别人用）。
  注意：onefile 的 exe 启动时要把内容解到系统临时目录，如果临时目录不可写会弹
  「Could not create temporary directory!」；这时检查 TEMP 环境变量指向的目录是否存在且可写。
  打包后的设置文件 epub_checker.ini 会写在与 exe 同一个目录（源码运行时写在脚本目录）。

【说明】
- 本工具无需安装；运行时依赖已随包提供的 Python 环境（PySide6 6.12.0）。
- 窗口大小、列宽、上次过滤条件保存在程序目录的 epub_checker.ini，可直接删除重置；升级版本后列宽会自动回到该版本默认值。
- 「孤儿图片」是提示项，不计入问题；合并式 EPUB（一个文件含多本子书）可能误报。
- 编辑工具（目录/封面）只处理 EPUB；不会改动原书，结果都是新文件。
- 文字版 PDF 的「逐字」比对仍不支持（需额外组件）；文字比不了时，只要两侧都有页面图，会自动改按页面图比对。
- 图片版比对会做像素级确认；「疑似降级」指位置对应但像素差异大（多为源文件褪色/压缩），不算缺失。
- 旧版 tkinter 界面仍在 epub_check_gui_tk.py.bak，需要时可改回引用。
